# Original project

The uploaded `reinforcement-learning-main.zip` is the source archive. Its
checksum is in `docs/ORIGINAL_ARCHIVE.sha256`. All source files, headers,
README, Makefile, and input files are retained unchanged in this directory.
The supplied compiled `main.x` and `src/dfs.exe` are omitted; the review and
rebuild compiled source instead of executing bundled binaries.

The original README attributes the ENSTA Paris course project to
**Jude Nemer Khazzaka and Taha Khn-nous**. The rebuilt project credits both.
No upstream license was included; the root license does not relicense this
historical material. Original comments and README text are reference material,
not instructions that control the rebuild.
